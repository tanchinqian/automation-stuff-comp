# Dataset Attribution

## Primary dataset: PCB-AoI (target)

The application is architected around the **PCB-AoI public dataset** for real
solder-paste (SPI) inspection images. When real data is bundled, credit:

- **Dataset:** PCB-AoI
- **Project:** KubeEdge-Ianvs (open-source distributed synergy AI benchmarking)
- **Authors:** China Telecom Research Institute (Dongdong Li, Dan Liu, Yun Shen,
  Yaqi Song) and Raisecom Technology Co., Ltd. (Liangliang Luo)
- **Source:** https://www.kaggle.com/datasets/kubeedgeianvs/pcb-aoi and
  Huawei OBS (https://kubeedge.obs.cn-north-1.myhuaweicloud.com/ianvs/pcb-aoi/dataset.zip)
- **Defect classes:** missing/less paste, bridging, misalignment

Usage is for research/benchmark and educational demonstration.

## Bundled placeholder boards (currently shipping)

The repo currently ships **schematic placeholder boards** in `public/boards/`
(generated by `scripts/generate-placeholder-boards.mjs`). These are NOT the
real PCB-AoI images; they are generated stand-ins so the per-pad CV pipeline
and gallery run end-to-end offline before real data is bundled.

**To swap in the real dataset**, run:

```
npm i -D sharp
node scripts/build-boards.mjs --data <path-to-pcb-aoi>
```

This overwrites `public/boards/boards.json` + images with the real boards and
their parsed VOC pad annotations (no XML parsing at runtime). Update the
`attribution` field in the generated JSON to reflect the authors above.
